# Poster checklist (ISEF items 231–240)

- [ ] Title states the result, not the topic
- [ ] One story: need → question → method → result → limits → next
- [ ] Results panel is the largest: scatter with 1:1 line, confusion table with CIs, LOD figure
- [ ] Every graph: axis labels with units, n, error bars or intervals, data source and date
- [ ] Every number traceable to `Analysis/out/poster/index.md`
- [ ] Simulated/demo data labelled at the same size as the result, or absent
- [ ] Limits panel: LOD vs legal limit, species, interferents, sample size, simulated training data
- [ ] Safety panel: what was hazardous, how handled, no arsenic at the booth
- [ ] Three colours + neutrals; one typeface; readable from 1.5 m; colour-blind safe (Okabe-Ito)
- [ ] Printed QR to the repository / dataset DOI (`project_figures.py qr`)
- [ ] English labels short; one Hindi alert screen as an example
- [ ] Display rules checked (no photos of people without consent; no organisms; no chemicals)
- [ ] Three strangers read it and answered: what did they find, how do they know?
