Device simulator
Handheld meter · MAS-G1 electrochemical system

Device display simulator

A working copy of the meter's screen. Run a demo scan, or import real voltammetry CSV files and a calibration file from the analysis script — the meter finds the arsenic peak and converts it to mg/L exactly like the hardware.

1 · Try a demo

Press DEMO on the device. It simulates a scan, draws the voltammogram and shows the result with a safety flag.

2 · Import scans

IMPORT SCAN DATA accepts one or more CSV files with the columns potential_mV and current_uA.

3 · Load calibration

IMPORT CALIBRATION loads calibration.json from the analysis script, replacing the default slope 0.8563 and intercept 0.0096.

4 · Export results

The meter stores the last 100 results. CSV exports them for the dashboard report or a spreadsheet.
